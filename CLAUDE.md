# Workflow

- Never open pull requests. Commit and push directly to `main`.
- After every change, rebuild with `npm run bundle` and republish `dist/car-simulator.html`,
  with the files of `dist/data/` beside it (same paths, `data/...`), to the Car Simulator
  artifact: https://claude.ai/artifact/FVcQTr9Hsg3TtqqypemS39
